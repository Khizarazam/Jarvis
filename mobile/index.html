⚙ Settings

This changes what the microphone listens for, the voice used to reply, and (for the first 6 languages) also translates Jarvis's replies. Roman Urdu/Hindi commands are understood regardless of this setting.
Voices are provided by your phone/browser, not by this app. If no Urdu male voice shows up, install one: Android → Settings → System → Languages & input → Text-to-speech output → (gear icon next to the engine) → Install voice data → Urdu. Then reopen this page and check here again.
